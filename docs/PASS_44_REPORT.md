# PASS 44 - Public Product Inversion

## Goal
Make the human story the product and move evidence machinery behind one explicit inspection path.

## Public contract
1. Three bill choices only.
2. One story headline.
3. One 30-second explanation.
4. One continuous human story.
5. One **CHECK MY HOMEWORK** control.
6. Receipts stay hidden until the citizen asks.

## Deliberately not shown on first screen
Rosetta grammar, atomic events, investigation scores, Truth Court internals, provenance classes, agent roles, schema names, confidence dashboards.

## Evidence behavior
The drawer uses only previously cleared artifacts. TCJA receipts expose selected court-cleared facts and source excerpts; IRA receipts expose verified cold-trial facts; ACA exposes the Reality Stack's primary-source lanes.

## Human gate
If the first screenshot feels like a dashboard, this pass fails. The desired reaction is: **“This looks like an article. I can inspect the machinery if I want to.”**
